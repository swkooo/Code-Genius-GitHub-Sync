# Code Genius GitHub Sync v0.4.1

Code Genius에서 제출에 성공한 코드를 사용자가 선택한 GitHub 저장소에 업로드하는 Chrome 확장 프로그램입니다. Java와 Python 풀이를 언어별 폴더로 정리하고, 문제별 README를 생성합니다.

## 주요 기능

- Code Genius의 제출 및 채점 결과를 감지합니다.
- 제출 성공 결과를 확인한 뒤 코드를 선택한 GitHub 저장소에 업로드합니다.
- Java와 Python 코드를 언어별로 분리합니다.
- 문제 번호와 제목을 기준으로 문제별 폴더 및 README를 구성합니다.
- 기존 저장소를 선택하거나 공개 저장소를 새로 만들 수 있습니다.

## 시작하기

1. Chrome 웹 스토어에서 설치한 뒤 확장 프로그램 설정 창을 엽니다.
2. **GitHub로 인증하기**를 눌러 본인 GitHub 계정으로 로그인하고 권한을 승인합니다.
3. 기존 저장소를 선택하거나 새 공개 저장소를 만듭니다. 기본 새 저장소 이름은 `CodingTest`입니다.
4. 브랜치와 저장 폴더를 확인하고 **저장소 연결 저장**을 누릅니다.
5. Code Genius에서 제출 성공 결과가 발생하면 설정된 저장소로 업로드됩니다.

확장 프로그램 설정 창은 툴바 아이콘 또는 `Alt+Shift+G` 단축키로 열 수 있습니다. 단축키는 `chrome://extensions/shortcuts`에서 변경할 수 있습니다.

## 저장 구조

```text
CodingTest/
└── CodeGenius/
    ├── Java/
    │   └── {문제ID}_{제목}/
    │       ├── Main.java
    │       └── README.md
    └── Python/
        └── {문제ID}_{제목}/
            ├── solution.py
            └── README.md
```

## 데이터 및 권한 안내

- GitHub 인증은 게시자가 운영하는 Cloudflare Worker를 통해 시작되며, GitHub OAuth로 인증합니다.
- GitHub 액세스 토큰, 선택한 저장소 설정, 제출 감지 상태 등은 Chrome 확장 프로그램의 로컬 저장소에 보관됩니다.
- 인증 중 OAuth 상태와 인증 결과는 Worker의 Cloudflare KV에 임시 저장됩니다. 인증 상태는 제한된 시간 후 만료되고, 인증 결과는 확장 프로그램이 가져가면 삭제됩니다.
- 제출 코드는 선택한 GitHub 저장소에 업로드하기 위해 GitHub API로 전송됩니다.
- OAuth 권한에는 `repo`가 사용됩니다. 이는 공개 저장소뿐 아니라 비공개 저장소에도 접근할 수 있는 권한이므로, 승인 화면을 읽고 본인이 허용할 범위를 확인하세요.
- 확장 프로그램은 Code Genius 사이트에서 제출/채점 관련 정보를 읽어 업로드 동작을 수행합니다. Code Genius 사이트의 구조나 정책이 변경되면 동작이 달라질 수 있습니다.

개인정보 처리에 관한 상세 내용은 게시자가 공개한 개인정보 처리방침을 확인하세요.

## 문제 해결

- 인증 창이 열리지 않거나 시간이 초과되면 확장 프로그램을 다시 열고 인증을 재시도하세요.
- 저장소 조회 또는 업로드가 실패하면 GitHub 인증 상태, 승인된 OAuth 권한, 선택한 저장소 접근 권한을 확인하세요.
- 업로드된 코드가 예상과 다르면 해당 제출 결과와 GitHub 저장소의 파일 경로를 확인하세요.

## 지원 및 이슈

오류를 제보할 때 액세스 토큰, Client Secret, OAuth `code` 값, 인증 URL 전체 등 비밀 정보는 공유하지 마세요.
