Code Genius GitHub Sync(이하 “확장 프로그램”)는 Code Genius에서 제출에 성공한 코드를 사용자가 선택한 GitHub 저장소에 정리해 업로드하는 Chrome 확장 프로그램입니다. 본 개인정보 처리방침은 확장 프로그램이 어떤 정보를 처리하고, 어떤 목적으로 이용하며, 이용자가 정보를 관리하는 방법을 설명합니다.

01 처리하는 정보

확장 프로그램은 기능 제공에 필요한 다음 정보를 처리할 수 있습니다.

  • GitHub 계정 정보: GitHub 사용자 이름 및 계정 식별자 등 인증된 계정을 확인하는 데 필요한 정보
  • 인증 정보: GitHub OAuth 액세스 토큰 및 OAuth 제공자가 반환하는 경우 갱신 토큰
  • Code Genius 제출 정보: 문제 식별자, 문제 제목, 제출 코드, 사용 언어, 제출 성공 여부 및 채점 결과 등 자동 업로드 기능에 필요한 정보
  • 사용자 설정: 사용자가 선택한 GitHub 저장소, 브랜치, 저장 폴더 등 업로드 설정
  • 상태 정보: 중복 업로드 방지 및 제출 처리에 필요한 임시 상태와 최근 처리 결과
확장 프로그램은 건강 정보, 금융·결제 정보, 위치 정보 또는 개인적인 메시지를 수집할 목적으로 설계되지 않았습니다.

02 정보 이용 목적

위 정보는 다음 목적에 한해 이용됩니다.

  1. GitHub OAuth 인증을 완료하고 인증된 GitHub 계정을 확인
  2. 사용자가 접근할 수 있는 GitHub 저장소를 조회하고, 사용자의 요청에 따라 공개 저장소를 생성하거나 기존 저장소를 연결
  3. Code Genius에서 제출 성공 및 채점 결과를 감지
  4. 사용자가 선택한 저장소에 제출 코드와 문제별 README를 업로드
  5. 제출 처리 상태를 저장해 중복 업로드를 줄이고 오류를 표시

03 정보 저장 및 전송

Chrome 확장 프로그램 저장소

GitHub 인증 정보, 사용자 설정, 제출 처리 상태 등 기능에 필요한 정보는 브라우저의 확장 프로그램 로컬 저장소(chrome.storage.local)에 저장됩니다. 해당 데이터는 브라우저의 확장 프로그램 데이터에 포함되며, 사용자가 확장 프로그램 데이터를 삭제하거나 확장 프로그램을 제거할 때 삭제될 수 있습니다. 제거 시 모든 관련 데이터가 즉시 완전히 삭제된다고 보장할 수는 없으므로, 필요한 경우 브라우저의 확장 프로그램 데이터도 직접 삭제해 주세요.

Cloudflare Worker 및 KV

GitHub OAuth 로그인 과정에서 확장 프로그램은 운영자가 관리하는 Cloudflare Worker를 사용합니다. Worker는 OAuth 인증을 시작하고, GitHub가 반환한 인증 코드를 액세스 토큰으로 교환하며, 인증 결과를 확장 프로그램에 전달합니다. 인증 절차를 이어 주기 위한 임시 세션 및 인증 결과는 Cloudflare KV에 임시 저장될 수 있습니다. OAuth 핸드오프 데이터는 제한된 시간 후 만료되도록 구성되어 있으며, 확장 프로그램이 결과를 가져온 뒤 삭제되도록 설계되어 있습니다.

GitHub

사용자가 선택한 저장소에 코드를 업로드할 때 제출 코드, 문제 제목 및 생성된 README가 GitHub API를 통해 해당 저장소로 전송됩니다. 전송된 콘텐츠의 보유 기간과 공개 여부는 사용자가 선택한 저장소의 설정 및 GitHub 이용 조건에 따릅니다. 공개 저장소에 업로드한 코드는 다른 사람이 열람할 수 있습니다.

확장 프로그램은 제출 코드를 자동으로 운영자의 GitHub 저장소로 보내지 않습니다. 코드는 사용자가 인증하고 선택한 GitHub 저장소에 업로드하기 위한 목적으로 처리됩니다.

04 제3자 서비스

확장 프로그램은 기능 제공을 위해 다음 서비스를 이용합니다.

  • Code Genius: 문제 제출 및 채점 결과를 확인하기 위해 사용자가 방문 중인 Code Genius 페이지의 관련 정보를 읽습니다.
  • GitHub: 사용자 인증, 계정 확인, 저장소 조회·생성 및 코드 업로드에 사용됩니다. OAuth 승인 화면에서 요청하는 권한에는 비공개 저장소를 포함한 저장소 접근 권한(repo)이 포함될 수 있으므로, 사용자는 승인 전에 권한 범위를 확인해야 합니다.
  • Cloudflare Worker 및 KV: OAuth 인증 흐름을 중계하고 인증 결과를 임시 전달하는 데 사용됩니다.

이들 서비스의 데이터 처리는 각 서비스의 개인정보 처리방침 및 이용약관의 적용을 받을 수 있습니다.

05 보유 기간 및 삭제

  • 브라우저에 저장된 정보: 사용자가 확장 프로그램 데이터를 삭제하거나 인증을 해제하고 관련 데이터가 삭제될 때까지 보관될 수 있습니다. 확장 프로그램을 제거하기 전에 브라우저의 확장 프로그램 데이터도 확인해 주세요.
  • OAuth 임시 데이터: 인증을 이어 주기 위한 임시 데이터는 Worker/KV 설정에 따른 제한된 만료 시간 동안만 보관되며, 현재 구성에서는 약 5분의 만료 시간이 적용됩니다.
  • GitHub에 업로드된 코드: 사용자가 GitHub 저장소에서 직접 삭제할 때까지 해당 저장소에 남을 수 있습니다. GitHub의 커밋 기록이나 백업 등에서 즉시 완전히 제거되는지는 GitHub의 정책에 따릅니다.

06 정보의 공유 및 판매

운영자는 확장 프로그램 기능 제공을 위해 필요한 경우를 제외하고, 이용자의 개인정보를 판매하지 않습니다. OAuth 인증 과정의 데이터는 인증 처리를 위해 Cloudflare Worker/KV와 GitHub에 전달될 수 있으며, 제출 코드는 사용자가 선택한 GitHub 저장소로 전송됩니다. 법령에 따라 요구되는 경우를 제외하고, 이 목적을 벗어나 개인정보를 제3자에게 제공하지 않습니다.

07 보안

확장 프로그램은 OAuth 인증을 사용하고 인증 정보 및 설정을 브라우저의 확장 프로그램 로컬 저장소에 보관합니다. 다만 인터넷 전송 및 로컬 장치 저장에 완전한 보안을 보장할 수는 없습니다. 이용자는 본인이 신뢰하는 기기에서 확장 프로그램을 사용하고, GitHub OAuth 승인 권한을 확인하며, 공용 기기에서는 사용 후 로그아웃하거나 확장 프로그램 데이터를 삭제하는 것을 권장합니다.

08 이용자의 선택 및 권리

이용자는 다음과 같이 데이터 처리를 관리할 수 있습니다.

  • 확장 프로그램 설정에서 GitHub 인증을 해제하거나 연결된 저장소를 변경
  • Chrome에서 확장 프로그램 데이터를 삭제하거나 확장 프로그램 제거
  • GitHub에서 OAuth 앱 승인을 취소
  • GitHub 저장소에서 업로드된 코드 및 README를 직접 삭제

GitHub OAuth 승인을 취소하면 확장 프로그램이 GitHub API를 이용하지 못할 수 있습니다.

09 아동의 개인정보

이 확장 프로그램은 일반적인 코딩 학습 및 개발 도구를 대상으로 하며, 아동의 개인정보를 의도적으로 수집할 목적으로 설계되지 않았습니다.

10 처리방침 변경

기능 또는 데이터 처리 방식이 변경되면 이 개인정보 처리방침을 갱신하고 시행일을 수정합니다. 중요한 변경 사항이 있는 경우 업데이트된 문서를 확인할 수 있도록 안내할 수 있습니다.
